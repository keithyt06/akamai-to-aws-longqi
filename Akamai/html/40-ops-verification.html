§1 运维原话复述（反馈源）

来自运维的 4 条原始反馈，作为本次交叉比对的事实基线。

FB-01静态资源缓存 365 天
TTL

.js .css 缓存 365 天；字体（常用后缀 woff/woff2/ttf/otf/eot）缓存 365 天；.jpg .webp 等图片缓存 365 天。

FB-02PC / M 通过域名 + 优先级规则分流
routing

PC 站和 M 站 ALB 通过域名区分 + 有优先级规则。

FB-03设备识别跳转（UA + 白名单）
redirect

设备间识别跳转走 UA 头；满足 LqPassWaf/851.3 不跳转；Mobile 访问 /.well-known/apple-developer-merchantid-domain-association.txt（Apple Pay 域名验证）不跳转。

FB-04首页 6h / 默认 NO_STORE / /blog 智能匹配
cache

www.beautyforever.com 首页 6h，默认 TTL = 0（运维口径 = NO_STORE）；/blog 或 /blog* 智能精确匹配子路径。

§3 初版文档的 7 个错误（复盘）

md 标题原为"4 个错误"，实际明细 7 条；下面按 ERR-01~ERR-07 列出。

ERR-01redirect 301 → 实际 302
已修正

影响范围：10-property §12、30/31 §5。

根因：只看了 behavior 名字 redirect，没看 options.responseCode 字段。

ERR-02漏 LqPassWaf UA 白名单
已修正

影响范围：所有 redirect 描述。

根因：criteria 数组只粗略看了头两个，没扫完。

ERR-03漏 Apple Pay .well-known 路径白名单
已修正

影响范围：M→PC 分支。

根因：同上，没把 criteria 跑完。

ERR-04漏 js/css 扩展名白名单
已修正

影响范围：两条 redirect。

根因：同上，fileExtension IS_NOT_ONE_OF 是第三个 criteria。

ERR-05漏 Hostnames 分支 origin + CP Code 覆盖
已修正

影响范围：10-property §3/§4、PC/M ALB 分流。

根因：只看了顶层 default 的 origin，没递归进 Hostnames 父规则。

ERR-06列表 & 详情页 cacheId 描述含糊
已修正

影响范围：10-property §7、30 §4。

根因：初版没写清是 EXCLUDE_QUERY_PARAMS + 34 个追踪参数，改后明确。

ERR-07Cache Tags 完全没提
已修正

影响范围：所有缓存表。

根因：把 cacheTag behavior 当成元数据忽略，没意识到运维是靠 tag 做 Fast Purge。

6.2 新发现（原文档未写）

① 双 Property 均有 staging-only HSTS 改动（prp_910841 v63 / prp_956325 v11）
激活时间 2026-01-06 08:35 UTC（仅 STAGING）；备注"配置 HSTS 两年"。
变更：httpStrictTransportSecurity = {enable:true, maxAge:TWO_YEARS, includeSubDomains:true, preload:true, redirect:false}
PAPI 告警："Enabling preload makes future downgrade to HTTP difficult."
影响：迁移到 CloudFront 时须同步配置 Response Headers Policy，并评估 preload 不可逆风险。
② Network List 146351_SECURITYBYPASSLIST 实际为空
elementCount=0, list=null, 最后更新 2023-02-16。
Akamai 默认创建的空 bypass list，业务上没有白名单 IP 生效。
原文档（20/30/31/99/40）都暗示它是有内容的 IP 白名单 —— 已在 20-waf §3 Target #1、30-www §7、31-m §7 纠正。
③ ASN 202425 拦截规则定位
Custom Rule id 60383229, name "Deny asnumber 202425 for www.beautyforever.com"
conditions = hostMatch(www.beautyforever.com) AND asNumberMatch(202425, useXForwardForHeaders=false)（均 positiveMatch=true）
operation=AND, tag=["as-number"], ruleActivated=true
不在 Network List / Penalty Box，是共享 WAF 配置下的独立 Custom Rule，hostMatch 限定只对 www 生效。
④ 同账号其他 *beautyforever* property（已在 00-account §2 列出）
